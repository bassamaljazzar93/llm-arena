الاستجابة
The issue is you're calling asyncio.run() inside an already-running event loop. Fix: Replace asyncio.run(coro()) with: loop = asyncio.get_event_loop() task = loop.create_task(coro()) result = await task Or use nest_asyncio if in Jupyter: import nest_asyncio nest_asyncio.apply() Root cause: asyncio.run() creates a NEW loop, blocking the current one → deadlock.
